# Definition of done

- **Requirement:** Scope is implemented and documented; compatibility, security, reliability, scalability, performance, cost, and operations are reviewed; generated artifacts match canonical sources; required checks pass; rollout/rollback and ownership are clear.
- **Why:** Code completion is not production readiness.
- **Enforcement:** PR template, `pr-readiness` skill, CI, reviewers, and release gates.
- **Exceptions:** Deferred work needs explicit owner, tracked item, deadline, and accepted risk.
- **Evidence:** Diff, executed commands, CI links, docs/ADR, risk record, and approvals.
